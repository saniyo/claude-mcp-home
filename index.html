Claude MCP (home)

Claude MCP (home) is a private, single-user tool. It lets the owner's own AI assistant, running on the owner's own computer, read the owner's own Gmail and Google Drive through the official Google APIs, to help sort and clean up that mailbox and storage.

It is not a public service: there are no other users, no accounts to sign up for and no server. Google access tokens are stored only on the owner's computer.

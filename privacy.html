Privacy policy

Last updated: 18 November 2026

Claude MCP (home) is a personal tool used only by its owner on the owner's own computer.

  • What it accesses: only the Google account(s) of the owner who grants access, with the scopes shown on Google's consent screen (read-only Gmail and Google Drive).
  • Where data goes: data is read directly from Google APIs to the owner's computer. It is not sent to, stored on or shared with any server or third party operated for this app.
  • Storage: OAuth tokens are kept in a local folder readable only by the owner's Windows user.
  • Google API Services User Data Policy: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: access can be removed at any time at myaccount.google.com/permissions.
